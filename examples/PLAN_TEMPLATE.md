# 影片規劃模板（plan_gate 可驗格式）

> 複製本檔開始規劃一支新片。寫完跑 `python src/longform_maker/plan_gate.py 你的規劃.md`
> —— FAIL 就代表還沒想清楚，不要動筆寫稿（包裝先行原則，見 knowledge/viral-playbook-framework.md 站2）。
> 本模板原樣跑一定 FAIL（這是刻意的）：佔位的 cluster 關鍵字、佔位或重複的「標題 | 縮圖」、
> 還沒有人簽的合規章，全部換成真內容才會過。

# 示範片0X 規劃

框架：成就            ← 成就/蛻變 或 工具/教學（成就框架通常 CTR 較強）
機器：推薦            ← 推薦（Browse 爆量線）或 搜尋（長尾資產線）
cluster關鍵字：你的主題詞   ← 標題/縮圖/開場語義全部對齊這個 cluster
合規：待複核          ← 只能由人簽：跑完平台 AI 內容政策 checklist 後，把整行換成「合規：通過 YYYY-MM-DD 複核：{你的名字}」並填入真實複核日期與複核人；程式與 AI 助手不代簽
Expected Views 對標：N 中位 x3   ← 近 30 支 trimmed median（快篩基準）
