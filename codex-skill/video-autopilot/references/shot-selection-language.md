# 依敘事風格挑選鏡頭

這份規則從製片人的選鏡建議提煉，只保留重新表述的判斷，不收錄原始文件。它是專業意見，尚未經作品盲審或觀眾成效證實，不能升格為全域美學分數。

## 用法

1. 先確定本片的敘事目的，再選一個主風格；題材如旅遊、產品、AI 不自動決定風格。風格可在片內段落變化，但每個段落要說明為何切換。
2. 對每顆候選鏡頭記錄來源時間碼、畫面或音訊觀察、段落用途、使用權與反例。沒有實際素材證據時，只輸出 `STYLE_CHOICE_REQUIRED` 或 `AWAITING_SHOT_EVIDENCE`。
3. 使用 `shot_selection_language.rank_shot_candidates` 的分數作人工挑選順序，不能把排序寫成已驗證的剪輯品質，也不能直接改 Editkin 時間軸。確定鏡頭後，才編入 Editkin v4 plan 並走 audit → apply → render → 創作者審片。
4. 若與真實性、人物意願、授權、劇情因果或已核准的美感方向衝突，這些條件優先；風格化選材只是可覆寫的偏好。

## 九種選鏡重點

| 風格 | 優先觀察 | 典型反例 |
| --- | --- | --- |
| 寫實 | 連續行為、自然反應、現場聲、觀察式機位 | 假反應或為炫技打斷事件；紀實訪談可以看鏡頭 |
| 風格化／藝術化 | 有意圖的構圖與色彩、象徵性動作、情緒留白 | 漂亮但與敘事無關的特效或空鏡 |
| 懸疑／恐怖 | 遮蔽與未知、延遲反應、聲音張力、有脈絡的揭露 | 先露答案或沒有事件承接的驚嚇 |
| 動作／冒險 | 清楚的動作方向、空間位置、反應時機 | 快剪到看不懂動作與人物位置 |
| 浪漫／愛情 | 雙向視線、彼此反應、帶關係意義的小動作 | 只靠單人表情推論雙方關係 |
| 科幻／奇幻 | 世界規則的可見線索、人物回應、空間尺度 | 沒有設定支撐的發光特效 |
| 人物強敘事 | 行為前後差、選擇時刻、關係轉折 | 孤立的強烈表情被當成完整人物弧線 |
| Vlog | 第一人稱互動、日常動作、說話與反應同步 | 把真實感誤解成內容模糊或聲音不可辨 |
| 商業廣告 | 可辨產品、實際使用、問題與解法、可核對差異 | 用誇張表情或 Logo 代替功效證據 |

`visual_director.py --shot-style <id>` 會把本段選鏡政策寫入 `shot_selection`，預設 `auto` 保留待選狀態。可用 ID：`realist`、`stylized`、`suspense_horror`、`action_adventure`、`romance`、`sci_fi_fantasy`、`character_drama`、`vlog`、`commercial_ad`。程式只接受有來源、用途和逐鏡證據的候選；沒有實際畫面時不猜演技、構圖、聲音或權利。
