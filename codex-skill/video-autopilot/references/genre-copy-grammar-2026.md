# 分類型文字語法（字幕＋文案共用）

> **PUBLIC_FIXTURE / privacy boundary:** public rules exclude maintainer raw quotes,
> dated incidents, internal draft wording and local outcome examples.
> Build attractive copy from verified concrete nouns, visible actions, contrast and payoff;
> reorder true facts for interest, but never invent a claim.

## 通用四刀（所有類型先過這關）

1. **名詞要具體**：「小吃店」→「豐衣足食」；「肉」→「蔥鹽雞」。讀不到就問 creator（user 來源），
   **不准用泛稱混過去**（M113）。
2. **每支片一個「為什麼要看完」**：hook 不是報地名，是丟一個沒解完的東西
   （「號稱平價版鼎泰豐」→ 看完才知道像不像）。
3. **砍清點、留 payoff**：一句只留最有感的那個細節，形容詞換動詞
   （「皮上整片起泡」留、「深淺兩種顏色」砍）。
4. **結尾給動作**：分享對象（「傳給那個說要約的朋友」）或下一步（「下次北海岸就停這裡」），
   不求讚。

## 第五刀：讀得完

每條字幕用「可讀字數 ÷ 停留秒數」檢查；舒適值與 fail 值由 creator profile 設定。
先決定畫面能停多久，再決定能放多少字。PUBLIC_FIXTURE 不包含私有抱怨原句、
店家專案或批次 pace。

## 分類型語法（📏=市面實測佐證 / ⚠️=樣本不足，先套近親語法）

### 🍜 美食（public generalized examples）
- 字幕優先寫畫面可證實的品名、價格與動作；慾望詞只在 payoff 使用。
- hook 先給具體口感、製程或反差，不預設任何真實店名。
- 價格可獨立成大字，但必須由畫面、菜單或核准來源驗證。
- 文案用具體名詞取代空泛形容，CTA 只留一個可回答或可分享的動作。

PUBLIC_FIXTURE: examples are synthetic and contain no maintainer restaurant project.

### 🏞️ 旅遊/景點（public generalized examples）
- hook 使用可由畫面或查證來源支持的意外性與反差。
- 用人物、道路或建築作比例尺；地名、歷史與交通資訊先查證。
- 畫面上的路牌、刻字與告示只有在可讀時才能引用。
- 結尾給一個行動；搜尋字詞由使用者自己的地點與研究 catalog 提供。

PUBLIC_FIXTURE: no maintainer route, backend sample or private travel transcript is included.

### 📦 開箱（📏 競品 toyboxjx：32s 只 5 刀、換句 75/分）
- **靜態特寫＋文字驅動**：畫面不夠動就讓字動（0.7-1.2s 一句連打）
- hook＝同好共感（「我就知道會有這一天」），圈內梗不解釋
- 結尾＝**提問 CTA 導留言**（開箱是唯一不用分享 CTA 的類型）；hashtag 中英雙掛

### 🎮 遊戲（📚 已網研入庫）→ 完整語法見 `genre-editing-craft-2026.md`
- 核心三條：爆點前置（最炸 1 秒複製到片頭）／每 2-3 秒一刀／end on impact 秒收做循環
- 升級路徑：丟樣本到 `<LOCAL_PATH>` 跑 teardown → 升 📏

### 🔧 DIY（📚 已網研入庫）→ 完整語法見 `genre-editing-craft-2026.md`
- 核心三條：成品爆閃開場→跳回爛材料／縮時骨架+2-3 個原速錨點（誠實壓縮）／收藏 CTA（「存起來週末做」）

### 🤖 AI 教學（主線，SOP 完整）
- 語音/字卡走 `yt-script-style` M101 voice＋M110 三支柱；Shorts＝長片切條
- hook＝真值戰績＋反差（「開源拿了 1,500 顆星，但它昨天抓到我 3 個錯」）；數字全走 M10
