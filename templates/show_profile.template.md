# Show Profile（模板）— 你的訪談節目識別

> 複製成 `profiles/show.md` 再填。`src/interview_autopilot.py` 讀這份，決定所有產出檔裡的
> 節目名 / 主持人 / 頻道 / 社群連結 / 發布平台 / 片尾招牌句。
>
> **沒填也能跑**：未填的欄位會在產出的檔案裡留下 `{你的…}` 字樣 —— 看到就知道那裡要補。
> 產出的授權書、發布套件、主持台本都會帶著這些字樣，交出去前記得掃一遍。

## 語法

- 單行欄位：`KEY: 值`（一行一個，`KEY` 全大寫）
- 多行欄位：`## KEY` 下面接一個 ``` 圍欄區塊
- 留 `______` 或留空 = 未填
