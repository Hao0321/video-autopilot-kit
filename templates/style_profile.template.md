# Style Profile（模板）— 從你自己的樣本建出「你的聲音」

> 複製這個檔成你工作區裡的 `style_profile.md` 再填（例如 `profiles/style_profile.md`）。
> **這份表沒有任何一格能靠猜。每一格的答案都在你自己的舊稿裡。**
>
> 跟 [`voice_profile.template.md`](voice_profile.template.md) 的分工：
> - `voice_profile` = **5 分鐘最小版**，只要能讓 AI 寫出「大致像你」的文案就夠了。
> - `style_profile`（本檔）= **累積版**，餵越多樣本越準，而且 §5 會直接產出
>   [`../src/longform_maker/script_gate.py`](../src/longform_maker/script_gate.py) 吃的四層詞表，
>   讓「不像你」與「觀眾聽不懂」變成**機械擋得下來**的東西。
> 先填 `voice_profile` 開工，有空再回頭養這份。

---

## §0 怎麼用這份表（四步，之後只增補）

```
1. 餵樣本   → 收集 N 篇你自己寫過的腳本（建議 ≥5 篇起跑，10 篇以上才穩）
2. 逐字審計 → 用 §1-§7 的問題逐篇掃，答案累積寫進本檔（合併，不覆蓋）
3. 導出詞表 → §5 的表填完後，導成 audience_vocab.json
4. 機械擋   → 寫新稿 → load_vocab(...) → gate(text) PASS 才錄音
```

**鐵則：合併，不覆蓋。** 每次餵新樣本都是疊加。矛盾的地方標 ⚠️ 留著，
別急著刪——矛盾通常代表你有兩個 sub-mode，不是你前後不一。

**樣本要用「你自己寫的」。** 貼別人的稿進來，你會得到別人的聲音，而且你不會發現。

**懶人法**：把 §1-§7 連同 5-10 篇舊稿一起丟給 AI，說「照這些樣本回答每一格，
每一格都要標出你是從第幾篇的哪一句推出來的」。**要求它附出處**——沒有出處的那格就是它編的，刪掉重問。

## 附錄：第一次填的最短路徑

1. 找 5 篇你**自己最滿意**的舊稿，先填 §3.2（招牌）＋ §4（開場／結尾）——這兩節就能讓 ghost-write 像你了。
2. 跑一次 §5.0-§5.4 的詞表審計（30-60 分鐘），導出 JSON。**這是投報率最高的一節**：
   它把「觀眾聽不懂」從一種感覺變成一條會擋稿的規則。
3. §7 先全部留預設，跑三支之後再回來調。
4. 之後每寫完一篇新稿就回頭補 §1 台帳與 §5.5 新詞——profile 會越來越像你。

*這份模板取代「直接抄某個人的 voice」——你的頻道要用你自己的聲音。*
