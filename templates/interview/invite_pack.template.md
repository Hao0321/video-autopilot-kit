## 版本 A｜熟人（社群裡認識、聊過天）

```
((來賓名)) 嗨！想邀你上我頻道錄一集對談 🎙️

((亮點句))
節目叫「((節目名))」，格式很簡單：線上錄，主畫面放你的作品和數據，
不用露臉也可以。

大概 40-50 分鐘，聊你怎麼做到的、中間卡在哪、方法怎麼運作。
不用準備稿子，我會帶問題。剪好會先給你看過才發。

有興趣的話我把細節傳給你？
```

```

((亮點句))
我在做一個叫「((節目名))」的對談單元，專門找「真的做出成果的人」

想邀請你來聊一集：
・線上錄製，約 40-50 分鐘
・主畫面是你的作品／數據，露不露臉都可以
・剪輯後你有審看權，不想播的段落可以拿掉
・發布後也歡迎你分享給自己的受眾

不知道你近期方不方便？
```

```

((亮點句))
我正在製作一個對談單元「((節目名))」，邀請實際做出具體成果的創作者，
拆解他們的方法與過程。想邀請您參與一集。

形式說明：
・線上錄製，約 40-50 分鐘
・節目以作品與數據畫面為主，是否出鏡由您決定
・發布前提供初剪供您確認，任何段落都可要求移除
・免費內容合作，無金錢往來

若有興趣，我再提供完整流程說明與同意書。感謝您撥空閱讀。
```
