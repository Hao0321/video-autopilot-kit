# Professional media workstation audit

This card is selected only for professional Timeline, creative-library, typography, color, director-review, or decoded-output claims.

- `cleanup.media.editable-journey`: source/rights manifest → packaged bytes → visible preview/apply → persisted editable graph → Undo/Redo → decoded render. Component presence or a synthetic planner benchmark is insufficient.
- `cleanup.media.timeline-interaction`: measure frozen large-project viewport/materialization and pointer/keyboard input-to-visible-state p50/p95. A gesture must retain pointer capture, render each sampled move, and commit exactly one canonical command on release.
- `cleanup.media.first-source`: exercise real picker/drop for portrait, landscape, near-square, invalid, and later-import fixtures; persist canvas/source identity and prove save/reopen/render geometry.
- `cleanup.media.font-export`: bind font license/provenance/hash through payload and resolver to an exported frame, with a missing-font fallback negative.
- `cleanup.media.color-order`: preserve declared input normalization → grade → look → graphics/output order; test SDR/HLG/PQ/unknown-Log and decoded output rather than source-only scopes.
- `cleanup.media.human-review`: machine readiness and automated warnings cannot create human approval/certification. Persist human action and audit identity separately.
- `cleanup.media.decoded-evidence`: sample claim-critical overlays and final audio from encoded output; test flicker/off-screen/contrast, semantic preserve ranges, loudness, true peak, and safe area.
- `cleanup.media.editorial-cardinality`: independent evidence determines expected N editorial units; require N distinct editable projects, renders, receipts, and fingerprints. Prior generated outputs are not self-labeled ground truth.

Use `../cross-system-integration-audit.md` only for the legacy full-detail contract or rare edge not represented here.
