# Retopology / continuity audit (provisional)

Read the [full tests and limits](character-retopology-audit-detail.md) before applying a checkpoint. Confirm the current production profile; preferences are not capabilities. Crooked faces need pose/shape diagnosis first.

- `cleanup.retopology.anatomy`: native wire/clay, eye/lip, bidirectional silhouette/boundary checks. Automatic quads can erase openings; reduced polygons and poles do not prove smooth anatomy. Unstitched patches stay REVIEW.
- `cleanup.retopology.transfer`: current source hashes, part/corner correspondence and skin/morph retests. Chart-aware UV transfer needs native albedo comparison; export is not Unreal acceptance.
- `cleanup.retopology.resume`: use R&D's hash-bound checkpoint helper. Missing, malformed, escaped, concurrent or stale evidence blocks reuse. CURRENT is not approval; retain rejected methods and open gates.
- `cleanup.retopology.cost`: measure context, time and retries with native art gates. Shorter prompts do not prove repair quality; retrieve full local evidence when needed.
- `cleanup.retopology.game`: actual PC/mobile evaluated triangles, LOD/texture budget, high-to-low bake, UV/cage/source hashes, normal/seam checks. Dense quads or copied texture do not deliver this; deformation/device performance remain separate.
